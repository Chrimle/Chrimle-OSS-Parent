
> ### Maven POM Parent for Chrimle's OSS Projects.

>

> This project contains:
> - Dependencies
>   - Dependency Versions
> - Maven Plugin
>   - Maven Plugin Versions
>   - Plugin Management
>     - Maven Central Publishing
>     - JavaDocs Publishing
>     - GPG Signing
> - Meta Information for [Chrimle](https://github.com/Chrimle)'s Projects.
